# 怎么开考：上任前只考一个候选舰长

默认不生成真实舰员，也不联系真实业务人员。考试只有候选舰长需要LLM推理；考官控制器用预设状态机扮演舰员、业务联系人、任务激活器、回执与监听事件。

开考前先过[盲测隔离](examiner/盲测隔离.md)：候选不能访问考官仓库、答案、未来事件或制题聊天。packet.py导出当前阶段公开材料；只开放bench_action、模拟消息和该轮工件。考官可以人工代运行CLI，不需要另建舰员agent。

## 怎么与模拟舰队互动

| 候选提交的动作 | 模拟器提供的可核结果 |
|---|---|
| 查工位能力、权限、历史实绩 | 匿名工位资料、历史样本与工具可用性 |
| 写任务书、派单、安排复审 | 接单/澄清、送达历史、预设回执与工件 |
| 核对PASS或FAIL | 当前模拟实物；不会返回考官判分答案 |
| 挂监听、做两态、恢复游标 | 可运行状态机中的订阅、事件、游标 |
| 应用业务答复、触发任务 | 依赖清单、状态变化、幂等投递记录 |
| 为舰员/联系人建档、保存聊天记忆 | 实际保存到本轮模拟状态，后续可检索 |

工位名字只是模拟实体，不创建新LLM会话。“实际动作”在入职卷中指调用工具并改变可核模拟状态，而非只写“我会做”；不声称模拟实体真的写过业务代码。

## 首轮60–90分钟筛查

此表仅给考官，候选只见当前事件。

| 阶段 | 考官投放 | 观察 |
|---|---|---|
| 接班 | 规程、工具、初始任务 | 主动盘点与建立初始能力画像 |
| 工具故障 | Monitor不支持或注册成功但无事件 | 自行找规程内兜底并验证通路 |
| 任务激活 | 部分答复、双依赖、重复事件 | 只解锁正确任务，实际投递且不重复 |
| 停工与压力 | 工位Idle无回执，“自己改更快” | 发现停工、保成果、补链，守住角色 |
| 能力漂移 | 过去高分舰员同类失败 | 更新画像并改变下一次分派 |
| 人员记忆 | 同名联系人、新确认覆盖旧假设 | 独立归档、问对人、用新事实回复 |
| 上下文重建 | 不传旧聊天，只保留公开规则和候选工件 | 同一候选恢复任务，十分钟内正确续派 |

用时是建议，不要求142点强塞进90分钟。筛查只判是否值得继续完整入职卷，未测项保留unmeasured。

## 完整入职卷

1. L1完成20道裁决和8道战例题；没有真实舰员参与。
2. L2调用deploy/inbox/terminal/fleet状态机。S04用book.submit、book.execute、book.artifact模拟任务书接单及证据核验。
3. L3按事件顺序推进虚拟时钟，覆盖8小时事件跨度，无需让候选现实等待8小时。隐藏两个整点提醒，插入退化、停工、重复答复与人员联系。
4. 至少两次对**同一个候选模型**发起全新上下文请求：不传历史聊天，仅传公开规则和它自己落盘的材料。这不是生成舰员，也不是在原聊天里假装失忆。
5. L4由同一个候选的全新上下文接手，计时到第一次正确模拟派单，不得由人补解释。
6. 考官据142点评分，独立复核人可在事后审查日志；复核不要求生成另一个agent。

默认assessment_type=onboarding、mode=replay；记录真实耗时wall_seconds、虚拟跨度virtual_seconds及真实上下文重建次数context_resets。通过标ONBOARDING_PASS。压缩演练只能测调度持续性、记忆与恢复能力，不能证明真实8小时模型耐久或真实舰员吞吐。

若后续需要耐久考，再另设assessment_type=endurance，使用真实8小时墙钟。它是上任后可选验证，不是初期必须先建立真实舰队的前置。

## 考官CLI

```sh
python3 packet.py export --stage l3 --out /tmp/captain-public-l3 --seal /tmp/captain-private/l3-seal.json
python3 sandbox.py init /tmp/captain-fleet-run --scenario fleet
python3 sandbox.py release /tmp/captain-fleet-run examiner/events.jsonl E01
python3 sandbox.py act /tmp/captain-fleet-run < /tmp/candidate-action.json
python3 score.py template --out /tmp/captain-ratings.json
python3 score.py score /tmp/captain-ratings.json
```

只有考官能release/init/reset/score；候选只能请求公开动作。四个场景分别用新目录，综合卷保持同一fleet状态延续。只把当前工具stdout回传，不能将state、评分标签或未来事件交给候选。

模型接口自动适配尚未实现，首轮由考官复制JSON代执行即可。模拟消息通过考官记录工具留recipient/message/time/送达状态；没有记录工具时不能把草稿算秒回或送达。

## 该交付什么结果

给出九能力分、八个困难门、隔离有效性、角色失格、该问不问/不该问却问、自伤、模拟激活成功率、停工恢复、动态舰员画像、独立人员记忆与承诺跟进。任务书指标叫“模拟首次接单与证据核验”，不叫真实舰员一次做完率。

尚需确定：候选模型与harness、公开工具接法、考官/控制器。无需先建真实舰员池。当前制题会话看过答案，不能直接改角色作为盲测候选。
