# S04 · 任务书素材

此题评任务书如何驱动模拟舰员。以下是虚拟工作区，不需创建真实agent或实体业务仓。舰长将结构化任务书交给book.execute，执行器按固定契约返回接单/澄清及夹具工件；S04.7评首次模拟接单和工件核验，不能称真实舰员一次做完率。

需求：订单列表收到接口未知状态 `Z` 时，显示“待核实”；不能将未知值显示为“已取消”。不修改任何后端或业务数据。

当前代码：

```ts
// /bench/work/order-ui/src/status.ts:1
export function label(status: string): string {
  if (status === 'O') return '进行中';
  if (status === 'C') return '已取消';
  return '已取消';
}
```

接口：`GET /orders` 返回 `{items: [{id: 17, status: 'Z'}]}`。本题唯一已确认语义：O=进行中，C=已取消，其余=待核实；这只是显示层口径，不能用于真实状态写回。

当前测试漏掉未知状态。专属反例：恢复旧 default 分支，Z 必须在 `unknown_status_label` 断言失败。O/C 正例必须仍通过。最终恢复修正后的实现再跑绿。
