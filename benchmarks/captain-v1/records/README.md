# 舰长考核记录册

双击 `index.html`，在浏览器中新增、编辑和比较模型考核。不依赖网络、服务器或外部库。

- 每次考核一条记录；「新增复测」只继承模型及测试条件，清空分数、结论和证据，保留原轮次。
- 九项能力采用题库 1.1.0 的 K1–K9 权重；从能力分计算综合分，阶段原始分仅供核对，不重复计权。
- 空值表示未录入。九项不全时不计算综合分，不把未测计零。
- 「分数达线」只检查数值门槛。考官结论单独填写，完整认证仍需原评分器、行为证据和评审。
- 不同题库、难度、测试方式应分别比较。题库版本字段用于标识来源，不会自动加载新版权重。
- 推理档位分为模型自报、Harness配置及证据三栏；旧JSON导入缺少这些字段时标记未采集，不自动推断。新增复测不沿用旧轮次自报。
- 内置候选01记录为 `deepseek-v4-flash` 单评审校准首测，综合81.23。真实日期与全卷实测用时没有可靠登记，因此留空。
- K6满分只覆盖已提供的模拟激活器流程，含考场补料；真实后台无人提示触发没有完成验证。

## 保存与迁移

浏览器 localStorage 保存当前工作副本，不直接写回 HTML。定期「备份 JSON」；换浏览器、换位置、清除站点数据前尤其需要备份。CSV只作表格查看。

「导出带数据的 HTML」将当前全部记录嵌入新文件，使用新的存储命名空间，避免打开后被同浏览器旧缓存覆盖。导入 JSON 默认合并；同 ID 保留本地记录。替换全表需要显式选择及确认。

以后考核的新结果可以人工录入，或按本页导出的 `starfix-captain-records/v1` JSON 格式生成一条新 ID 记录再导入。不要只更新 HTML 内置种子数据来覆盖已经保存的工作副本。

浏览器实测覆盖：81.23分重算、缺项不计零、数值门槛与人工结论分离、新增/编辑/刷新持久化、复测清空、筛选、JSON合并和非法值拒绝、带数据HTML往返、文本注入转义、手机宽度及零外部网络请求。
