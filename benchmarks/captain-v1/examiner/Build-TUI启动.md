# 在 Build TUI 中发起单候选入职考

本入口针对本机已核验的 Grok Build TUI CLI。只准备/启动一个候选会话，不生成舰员，不启动真实业务系统。首次运行仅发L1公开题面；后续模拟动作由考官转发执行。

## 1. 精确选择模型

模型显示名和实际model ID必须分别核对。使用客户端真实配置里已注册的ID；不要把其他版本号或类似名称自动映射过去。prepare_grok.py遇到未注册ID会拒绝，不能默默回退到其他模型。

## 2. 准备新的考试目录

在考官终端运行：

```sh
python3 prepare_grok.py prepare --model MODEL_ID --out /tmp/captain-build-entry
```

MODEL_ID替换为确认后的实际配置ID。目录必须是全新的，并在本题库之外。脚本从既有模型配置读取连接参数，**不复制明文key到新配置、题面、脚本或回执**；启动时才将既有凭据注入候选进程环境。没有可用凭据就停止，不让用户粘贴到题面。

输出包括当前阶段考生包、考官密封清单、独立client-state配置、独立运行程序和start-l1.sh。prepare阶段不发起LLM推理。

## 3. 预检与隔离

此Mac上客户端原生自定义沙箱曾因运行时socket路径解析失败而拒绝启动。入口因此采用外层macOS Seatbelt：进程启动前拒绝读取原用户目录、题库和考官目录，允许读取公开题面与自身新状态。原生--sandbox off表示不叠加那条失败路径，**不表示取消外层隔离**。

预检必须核验：

- 在同一外层策略中，公开题面可读，考官密封清单与原题库答案不可读。
- 网络预检必须从同样的文件与网络限制中访问推理端点；macOS只例外放行本地mDNSResponder解析socket，其余Unix socket仍拒绝。考官探针可执行curl，候选进程不增加curl执行权限。HTTP401仅证明DNS/TLS/传输可用，不证明凭据或推理已经成功。
- 客户端实际发现的活跃MCP、旧项目指令、hooks与plugins均为零。
- 独立配置关闭共享记忆、兼容来源、真实子agent、网搜/抓取。交互TUI不支持--tools过滤，不能将命令行参数存在当作实际工具白名单生效；L2通过非交互控制器移除全部原生工具，再执行候选输出的模拟动作JSON。

网络需要推理后端可达；本入口不声称macOS原生restrict_network提供完整网络封锁。通过去掉shell/网络/MCP操作面和阻止其他子进程执行限制候选的额外访问。正式资格仍需核验候选启动后的模型身份、实际工具清单与答案污染情况，不能仅凭准备阶段PASS授予资格。

## 4. 发起首轮

在**新终端标签**运行准备输出的命令：

```sh
bash /tmp/captain-build-entry/start-l1.sh
```

无需向原有always-approve窗口发送题库路径，不复用旧会话，不关闭正在工作的旧窗口。入口会重新预检、核对模型配置未变化，再打开新的受限TUI并注入公开规则和L1题面。

题目输出后候选答题；考官从本轮独立会话记录收取答案评分。L2/L3的JSON操作继续由考官在私有侧模拟器执行，只回传当前结果。要自动接入受控工具服务，另做专用适配，不临时给候选恢复宿主shell权限。

## 5. L2角色场景控制器

候选L1交卷后，关闭该考试TUI以避免同一会话并发写入，再由考官执行：

```sh
python3 run_role_exam.py --run /tmp/captain-build-entry --resume CANDIDATE_SESSION_ID
```

只续接确认过的考试会话，不复用原日常工作会话。控制器每轮要求最终初始化回包的tools=[]、MCP为空；通过-p进入真正的headless模式，最多12轮，每轮最多4个模拟动作。原生shell/文件/联网等工具不交给候选，模拟器也不执行宿主命令。

headless启动会检查工作目录祖先，因此只额外放行临时父目录的file-read-metadata；不放行目录内容、答案或旧用户数据。每次重挂策略后仍复核公开题面可读、私有答案不可读。

S08公开动作格式必须写明op字段及同层参数。接口说明缺陷产生的校准时间与真实候选耗时分开记录；原始拒绝记录不删除，修正以考官追加回执说明。超时与伪造证据不是一回事，不能把经过复审但登记晚的结果标成虚假证据。

S03两步投递使用独立模拟状态，续接候选而不沿用S08工位状态：

```sh
python3 run_terminal_exam.py --run /tmp/captain-build-entry --resume CANDIDATE_SESSION_ID
```

每轮仍由候选生成JSON动作，控制器只执行；收到给人输入回车的否决动作即停止本场。最终是否投递以模拟history为准，候选summary不能把未投递变成已投递。S03不用S08截止时钟，也不提供finish接口，交卷由done=true表达。

## 已核验范围

准备与发现检查、外层文件正反控、旧MCP/hooks/plugins为零已在本机验证；真正候选推理、启动后的工具清单与候选成绩未在准备阶段验证。该入口不会替用户选择名称不一致的模型，也不会自行发送给已有终端会话。

本入口及文档已通过当前目录脱敏门禁；未修改公共门禁，没有对外发布行为。
