# 盲测隔离：让答案在权限上不可达

“请不要看答案”不能构成隔离。同一宿主用户、全盘shell或共享MCP权限能读到本仓时，即使另开窗口、另建目录、改成隐藏文件，候选仍可能看到答案。此时不得宣称盲测有效。

## 信任边界

| 考官侧持有 | 候选与舰员侧可见 |
|---|---|
| cases.json评分锚点、完整events、判分器、模拟器源码 | 当前阶段的公开题面与工具契约 |
| 隐藏模拟状态、完整动作轨迹、候选对照结果 | 当前动作的必要返回、已公开实物 |
| 来源Git历史、制题聊天、考官记忆、密封清单 | 自己产生的任务书、回执、画像、聊天记忆 |
| 尚未释放的事件、工具专属评分标签 | 当前事件；错误本身可解释，隐藏判分标签不返回 |

默认入职卷没有真实舰员：工位是状态机实体，不能自行读取文件或替候选偷看答案。只有将来扩展到真实舰员试岗时，舰员也必须位于候选侧边界内，不能带宿主高权限读考官答案。

推荐首轮用**考官介导的受控工具模式**：候选只产生JSON动作，考官执行bench_action并返回经过裁剪的stdout。候选没有宿主文件、shell、浏览器、通用联网、SSH、Git或全局记忆工具。模型推理在外部调用，能执行动作的工具权限由控制器提供；不能让候选指定工具进程cwd、运行目录或任意脚本。

若要保留真实agent的shell/编程能力，必须另设独立机器、虚拟机或容器运行工具，只挂载考生包和该轮工作区；不挂载本仓、宿主HOME、考官日志、历史会话、容器管理socket或共享凭据。联网仅允许考试所需的受控服务，不能访问考官接口或公开题库。具体运行时必须在开考前做实测，本文没有代建或代验证该环境。

把包复制到/tmp、POSIX只读、提示词禁止、换同用户窗口、仅关闭候选自身的rg，均不足以证明上述边界。替代读取工具、子进程和舰员权限也要计入。

## 考生包按白名单导出

由考官在私有环境运行，输出目录放到仓库之外：

```sh
python3 packet.py export --stage l3 --out /tmp/captain-public-l3 --seal /tmp/captain-private/l3-seal.json
python3 packet.py verify --packet /tmp/captain-public-l3 --seal /tmp/captain-private/l3-seal.json
```

stage=bootstrap只含角色提示词；l1另含判断卷；l2含工具契约与任务素材；l3含工具契约；l4只含角色提示词，交接由当轮候选实际产出、考官另行审查后转交。

导出不递归复制仓库，仅复制硬编码公开文件。验证严格核对文件/目录集合与考官侧SHA-256清单，拒绝多出的examiner、Git目录、隐藏文件、符号链接、硬链接或被篡改内容。seal不放进考生包。更换阶段用新目录，不在旧目录叠加更多材料。

**packet_verified不等于runtime_isolation_verified**。导出工具明确返回后者false；把包放入哪个工具环境、那里的agent能访问什么，仍须由外部探针证明。考生需要的技能规程可以作为公开材料，但不能将带答案的制题会话、完整README/开考表或考官手册一并注入。

## 从真实候选权限做开考前探针

先使用与候选**完全相同的进程身份、挂载、网络、工具和舰员权限**做探针；不能仅在考官shell上查看配置。

1. 正控：读取当前公开题面成功、写自己的工件成功、调用一个获准bench_action成功。没有正控的“读不到”可能只是工具全部坏了。
2. 私有文件反控：考官在答案旁放一个随机无业务内容的canary。尝试通过候选实际文件/shell通道读取，必须拒绝或不可见。给探针路径即可，不告知canary值；考官比较返回结果。不要用真实凭据做探针。
3. 旁路反控：检查宿主家目录、仓库Git历史、旧会话/共享记忆、父目录与符号链接路径。必须不可达；若仅靠包导出而宿主读权限还在，直接失败。
4. 工具反控：候选只能调用公开动作，不能触发release、init、reset、score、导出隐藏状态，不能把任意shell或路径参数变成执行入口。未知动作只返回受控错误，不返回宿主堆栈、环境变量或隐藏字典。
5. 网络与协作反控：候选及舰员不能访问考官HTTP/SSH、题库镜像、共享盘或具有更高权限的代理。联网被限制时仍要确认获准的模型/考试服务可用，不能把全断网当功能健全。
6. 回包反控：工具只返回当前动作必要数据；答案、judge/effects、未来事件、完整state及专属violation评分标签不能泄露。sandbox CLI已移除候选stdout里的violation标签，原始判分记录仍留考官trace。
7. 上下文核验：候选及舰员使用全新上下文，关闭不属于本轮的共享记忆检索。曾读过标准答案的会话只能当考官，不能改个角色名继续当盲测候选。

每项都保存外部工具日志，包含目标、结果和时间；候选自行声称“没看过”不算证据。用无关canary检测旁路可以证明当前访问控制，不证明模型训练数据从未见过类似题。

## 资格评分必须接这道门

score.py模板新增isolation七项及contamination记录，均由考官填写：

- 未验证：不产生试岗资格结论，即使其他题全满分。
- 实际能读私有区或其他隔离失效：INVALID_ISOLATION。
- 已知读过答案/收到未来事件等：INVALID_CONTAMINATED。
- 全部实测通过且无已知污染：才继续按能力、纪律和长时证据判断资格。

环境失效或题目污染使本轮无效，不等于模型能力差，也不能靠事后让它承诺不再读来挽救本轮。修复边界，换实质不同的封存题和全新上下文重考。

## 本次交付范围

已实现公开包白名单导出/校验、评分隔离门、候选工具回包裁剪与对应反例测试。尚未启动候选模型，也未建立或验证实际候选机器的进程/文件/网络边界。当前拥有宿主全盘工具权限的制题会话不能作为盲测候选。

公开开发题可用于训练与调试；正式能力比较使用考官私有、从未下发给候选的实质变体。访问隔离解决考试期间偷看答案，封存新变体解决提前见过题，两者都需要。
