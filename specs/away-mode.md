# 离席模式（Away Mode / OA 接力）

**语言 / Language：** [中文](away-mode.md) · [English](away-mode.en.md)

Owner 不在终端前时，舰长的汇报与请示改走 IM 接力会话，直到 Owner 宣布回来。目的：Owner 在手机上也能拍板；舰长不因等待停摆。

## 一、进入与退出

- 进入：Owner 在 IM 或终端说「开启离席模式 / 我不在电脑前」。舰长回一句确认并写台账「离席开始 HH:MM」。
- 退出：Owner 说「我回来了」。舰长把离席期间的裁定、动作、待答清单在终端汇总一次。
- 离席期间 Owner 说「可以不关注此窗口」表示他不看该会话，舰长仍照常汇报但不等回复。

## 二、通道

- 请示：**双写**——决策面板 `ask add`（收件箱落库）+ IM 一条简报（题干 + A/B/C + 推荐，编号一致）。Owner 在哪边答都落同一收件箱。
- 汇报：只发结果与需要他决定的事；信息级进台账不发 IM。
- 对接人（员工）侧：离席期间对外口径权收敛——员工消息先秒回「收到」，实质答复先在 IM 请示 Owner，批了才回。

## 三、离席期间的自决范围

- 与在席相同：三类事上升（不可逆生产面 / 只有人类知道的业务事实 / 对外发布），其余自决 + 备案 + 可撤。
- Owner 若离席前一次性授权若干项（如「1 部署，2B，3A…」），按编号逐条执行并逐条回报，不扩大解释；「你自己可以搞定的不需要找我」=自决范围扩大到该次列出的事项，仍不含红线。
- 离席期间的部署：剧本必须已在、备份必须已做、回滚一句话；做完以「下一轮业务心跳成功」作收尾判据再报。

## 四、监听

- 加挂：Owner IM 私聊会话轮询（游标接续、只报人类消息）；面板收件箱落库。
- 业务健康危险侧同时推 IM；通道守护保证 IM 兜底路径可用。
- 离席结束：停私聊轮询，其余照常。

## 五、记录

- 台账逐条：时间、事项、走了哪条通道、Owner 答复原文（编号）、执行结果。
- 离席期间 Owner 的每句裁定都是「先例」，进决策清单供以后引用。
