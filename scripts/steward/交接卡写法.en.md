# How to write the handoff card (manual section)

The new session trusts only this card. There is no length limit; when in doubt, write it down.

1. **Current state** — the latest outcome on this line, in one or two sentences.
2. **Every item in flight** — who, which step, the criterion, the next step, the deadline (include window id if relevant).
3. **What the Owner decided in this session** — quote the original words; mark your own interpretation separately.
4. **What was tried and did not work** — how you tried and why it failed, so the new session does not repeat it.
5. **Promises made and replies awaited** — to whom and about what.
6. **What this session only just figured out** — pitfalls, tool usage, where things live.
7. **Evidence, receipts, ledger, task books** — paths only, no pasted secrets.
8. **Timers, monitors, background processes** — how to check they are alive and how to re-attach them, with commands verbatim.
9. **Carry over anything still valid from the previous card**; drop what expired.

Scrubbing rules unchanged: use role placeholders, no real names, domains, IPs or credentials.
